# Plan de citations et partenariats locaux (Yvelines, Eure-et-Loir)

Règles : actions **manuelles** uniquement, informations identiques partout (nom : Pulse Locale PME / HoldMasto, site, e-mail, zones), aucun faux profil, aucune adresse locale fictive, aucune publication automatique. Les conditions d'inscription sont à vérifier sur chaque site au moment de l'action (À VALIDER).
